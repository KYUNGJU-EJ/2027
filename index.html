고객 과제

결제·환불 구조 개선

구매 상품과 결제 내역을 연결해 환불 오류를 없애고, 결제 구조 때문에 막혀 있던 구매·제휴를 풉니다.

  1. 상품별 결제 구분

    • 항공권·부가서비스별 결제 내역 연결
    • 최신 결제순 환불 → 해당 상품의 원결제 기준 환불

  2. 타인 결제수단 환불 방지

    • 결제자 기준 환불 수단 검증
    • 환불 수단 안내 및 예외 처리 정의

  3. 일행 부가서비스 동시 구매

    • 일행 추가 시 승객별 부가서비스 일괄 구매
    • 구매 편의성 개선으로 부가서비스 부착률 제고

  4. 제휴 프로모션 제약 해소

    • 결제 구분 기반 제휴사·카드사 할인 적용
KPI
  • 환불 관련 CS 문의 건수개선 전후 비교
  • 환불 오류 건수타인 결제수단·결제 순서 오류
  • 부가서비스 부착률일행 예약 중 부가서비스 구매 비율
  • 예약당 부가서비스 매출
  • 제휴 프로모션 예약 수·매출
회사 과제 ①

CRM 역량 내재화

고객을 식별하고 세분화해 직접 프로모션을 운영하고, 성과를 측정하는 체계를 만듭니다.

  1. 직판 매출 분석 P1

    • 노선별 n회 이상 탑승 고객, 리드타임 분석
    • 핵심 고객 세그먼트 정의

  2. 핵심 고객 데이터 수집 · 타겟 프로모션 P2

    • 홈페이지 회원 대상 프로모션
    • 비회원 대상: 간접 채널 예매 고객, 홈페이지 비회원 예매 고객
    • 비회원·간접 채널 고객 식별 방법 정의
    • 회원 예매 유도 프로그램

  3. 프로모션 성과 분석 P3

    • 할인 이벤트·프로모션별 성과 측정 체계

  4. 시스템 구축 P4

    • 쿠폰 관리 시스템
    • 앱 푸시

  5. 로열티 프로그램

    • 마일리지 / 멤버십 구조 설계
KPI
  • 홈페이지 채널 매출 비중전체 항공권 매출 대비
  • 회원 예매 비중직판 예매 중 회원 예매 비율
  • 비회원 → 회원 전환 수
  • 재구매율핵심 고객 세그먼트 기준
  • 쿠폰 사용률 · 프로모션 ROI증분 매출 ÷ 할인 비용
  • 앱 푸시 오픈율 · 구매 전환율
